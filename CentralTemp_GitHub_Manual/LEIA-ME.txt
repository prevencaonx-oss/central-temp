CONTROLE DE TEMPERATURA - PACOTE PARA GITHUB

ESTRUTURA DO PACOTE:
- index.html
- assets/  (pasta com CSS, JavaScript, logo e mascote)

COMO ATUALIZAR NO GITHUB:
1. Abra o repositório: prevencaonx-oss/central-temp
2. Entre na branch main.
3. Clique em Add file > Upload files.
4. Envie o arquivo index.html e a pasta assets deste pacote.
5. Quando o GitHub perguntar sobre arquivos existentes, substitua os arquivos de mesmo nome.
6. No campo de commit, escreva: Atualiza Controle de Temperatura - pacote manual
7. Clique em Commit changes.
8. Aguarde o GitHub Pages concluir o deploy.
9. Abra: https://prevencaonx-oss.github.io/central-temp/
10. No computador, pressione Ctrl + F5 uma vez.

IMPORTANTE:
- Não altere a estrutura da pasta assets.
- O index.html deve ficar na raiz do repositório.
- Os arquivos app-01.js até app-09.js devem ficar dentro de assets.
- O pacote mantém a conexão com o Supabase já configurada.
- O login recebeu limites de tempo para evitar carregamento infinito.
- A logo NILO transparente está em assets/nilo-logo-transparent.png.
