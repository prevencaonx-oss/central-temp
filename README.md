# Central de Temperatura — NILO

Aplicação web de Controle de Temperatura para Prevenção de Perdas.

## Estrutura
- `index.html` — interface principal
- `styles.css` — identidade visual aprovada NILO / Triela
- `js/app.js` — autenticação, dashboards, coletas, alertas, relatórios, usuários e auditoria
- `assets/` — logos e mascote

## Backend
Supabase com autenticação, RLS, auditoria, alertas, incidentes e regras de proteção de histórico.
